المحتويات:
- index.html
- assets/logo.jpeg (الشعار الأصلي كما أرسله المستخدم)
- assets/construction-bg.jpg (صورة خلفية موقع الإنشاءات)

النشر على GitHub / Render:
1) فك ضغط الملف.
2) ارفع index.html ومجلد assets إلى جذر مستودع GitHub واستبدل الملفات القديمة.
3) اعمل Commit إلى main.
4) انتظر Render حتى ينتهي النشر، أو اختر Manual Deploy ثم Deploy latest commit.
